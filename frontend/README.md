# GNK Algo frontend

Next.js App Router workspace. Run npm ci, then npm run dev; the local API must listen at 127.0.0.1:8000. Open http://localhost:3000. Run npm run lint, npm run build and npm run typecheck for validation. The production Docker image starts the standalone Next.js server; local npm start is for build inspection. All account requests use same-origin /api/v1 and HttpOnly cookies. The guest workspace uses labeled demonstration values. See ../docs/ORACLE_UBUNTU_DEPLOYMENT.md for the complete setup.
